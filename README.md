Gradle tasks:
* Build the plugin and run a local Paper server that includes it:
  ```sh
  ./gradlew runServer
  ```
* Build a JAR file:
  ```sh
  ./gradlew build
  ```
* Build a JAR file, without running unit tests:
  ```sh
  ./gradlew assemble
  ```


You should install a permission plugin, such as [LuckPerms](https://luckperms.net/), if you want to try managing the permissions.
